Workflow

  • Draft. Upload questions or write them in the UI.
  • In review. Submit for a second pair of eyes.
  • Approved. A reviewer (a different person) signs off.
  • Locked. Frozen and ready to run against models.

Two-person rule

The approver can never be the author. This is enforced in the service layer and recorded in the audit log, so it holds even when someone clicks fast.

Reproducibility

Only locked sets can be evaluated. Every run keeps the raw model output, provider metadata, parsed answers and per-category scores in the database for later comparison.
